The original application's README describes it as a free public beta with proprietary application code; this port does not relicense it or represent it as open-source software. The RG35XX compatibility adapters retain their original headers and RG40XX H patch attribution.

Original project demo audio and AMBIENT preset are retained. No user recordings, personal sample libraries or custom projects are included.

Third-party notices, licence files and provided sources remain under `THIRD_PARTY_NOTICES.md`, `THIRD_PARTY_LICENSES/`, `THIRD_PARTY_SOURCES/` and the bundled NumPy package. These include SoundTouch and its original bridge/source notices. Python, Pygame, SDL and ALSA utilities are supplied by the supported KNULLI operating system; the port uses those system components.

Stardust is an independent native ARM shimmer implementation added by AntevasinBuild. Its C source and build helper are under experimental/v4-live/stardust in the repository. Luminance by Sinevibes was supplied as a control/sound reference; no Luminance plugin binary, artwork or preset bank is distributed in this build.
